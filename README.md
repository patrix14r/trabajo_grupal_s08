# Caso: Sistema de Apilamiento de Platos (Estructura de Datos: Pila)

Implementación y análisis comparativo de una estructura de datos tipo **Pila (Stack)** basada en el principio **LIFO** (*Last-In, First-Out*), 
aplicada a la gestión operativa de platos en la cocina .
